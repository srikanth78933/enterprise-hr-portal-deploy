Enterprise HR Portal {{ .Chart.AppVersion }} is deployed to namespace "{{ .Release.Namespace }}".

Check the resources:
  kubectl get pods,svc,hpa,pdb -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }}

{{- if .Values.ingress.enabled }}

Get the application URL (the ALB can take 2-3 minutes to become reachable):
  kubectl get ingress {{ .Release.Name }} -n {{ .Release.Namespace }} -o jsonpath='{.status.loadBalancer.ingress[0].hostname}'
Then open http://<that-hostname> in your browser.
{{- else if eq .Values.service.type "LoadBalancer" }}

Get the application URL (the load balancer can take 2-3 minutes to become reachable):
  kubectl get svc {{ .Release.Name }} -n {{ .Release.Namespace }} -o jsonpath='{.status.loadBalancer.ingress[0].hostname}'
Then open http://<that-hostname> in your browser.
{{- else }}

Open the application locally:
  kubectl port-forward svc/{{ .Release.Name }} 8080:{{ .Values.service.port }} -n {{ .Release.Namespace }}
Then open http://localhost:8080 in your browser.
{{- end }}
